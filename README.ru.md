# Claude Hub (webhub) для Claude Code

[English](README.md) | Русский

Боковая панель в приложении Claude Code маленькая и простая. Claude Hub даёт модам настоящую страницу в браузере: любой HTML, CSS и скрипт, обновление вживую и кнопки, нажатия которых приходят Claude сообщениями.

Хаб — основа, к которой подключаются моды. Он запускает один небольшой локальный сервер, держит у себя страницу каждого мода, показывает их на главной по сессиям (с названием сессии) и по проектам, передаёт странице состояние мода и возвращает моду то, что ты нажал. Своих страниц у хаба нет: их приносят моды.

## Что это даёт

- **Один адрес для всех модов.** На `http://localhost:7777` собраны все страницы, которые открыли твои моды, в группах **Проекты**, **Активные** и **Завершённые** сессии, с поиском, счётчиками того, что ждёт тебя, и ссылкой «открыть в отдельной вкладке».
- **Страницы сессии и страницы проекта.** Страница сессии принадлежит одному чату (вопросы Claude, доска задачи). Страница проекта общая для всех сессий одного git-репозитория (запуск тестов, мониторинг): нажатие уходит в сессию, где ты писал последним, или в ту, которую указывает страница.
- **Вживую и без потерь.** Состояние сразу приходит во все открытые вкладки; нажатие хранится, пока мод его не подтвердит, и страница показывает «Доставлено». Страницы и их состояние переживают перезапуск хаба и Claude.
- **Три языка и две темы.** Английский, русский и украинский; светлая, тёмная или как в системе. Страницы модов следуют выбору.
- **Удалённые сессии.** Claude Code на сервере по SSH работает так же: пробрось порт и открой хаб в локальном браузере.

## Что нужно

- **Docker** на машине, где работает Claude Code. Мод сам запускает сервер в контейнере `claude-webhub` (`node:20-alpine`, перезапускается докером, слушает только `127.0.0.1`).
- Сборка Claude Code с поддержкой модов (плагины с модулем хуков).

## Установка

В строке ввода сессии Claude Code:

```
/plugin install webhub --marketplace jabenb/claude-webhub
```

Из терминала:

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub
```

В десктопном приложении Claude: **+** рядом с полем ввода, **Plugins**, **Add marketplace** с `jabenb/claude-webhub`, затем **Add plugin**.

### Глобально или в один проект

| Область | Где работает | Куда записывается |
|---|---|---|
| `user` (по умолчанию) | во всех проектах | `~/.claude/settings.json` |
| `project` | в этом репозитории, у всех, кто его клонирует | `<проект>/.claude/settings.json`, в коммит |
| `local` | в этом репозитории, только у тебя | `<проект>/.claude/settings.local.json`, не в коммит |

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub --scope user
claude plugin install webhub --marketplace jabenb/claude-webhub --scope project
```

Ставь хаб туда же, куда ставишь мод, который с ним работает: такой мод указывает `webhub` в зависимостях.

## Как пользоваться

1. Запусти сессию. Сервер хаба поднимется сам при первой сессии (в первый раз скачается образ `node:20-alpine`).
2. Выполни `/hub` в сессии, чтобы увидеть адрес, и открой его в браузере.
3. Моды, которые работают через хаб, выкладывают туда свои страницы; открой нужную из списка.

### Claude Code на удалённом сервере

Сервер слушает `127.0.0.1:7777` удалённой машины. Пробрось порт со своей **локальной** машины и не закрывай команду:

```bash
ssh -N -L 7777:127.0.0.1:7777 <хост>
```

Потом открой `http://localhost:7777` локально.

### Настройки

Задаются при установке или позже в `/plugin`:

| Настройка | По умолчанию | Что это |
|---|---|---|
| `port` | `7777` | Локальный порт сервера. |
| `publicUrl` | пусто | Адрес хаба в твоём браузере, если это не `http://localhost:<port>` (проброс на другой порт, туннель). Его используют ссылки, которые показывают моды. |

## Как написать мод для хаба

В плагине есть скилл `webhub-mod` с готовым шаблоном мода: попроси Claude «сделай мод для хаба, который …», и он начнёт с шаблона. Коротко:

- Мод указывает `"dependencies": ["webhub@claude-webhub"]` в своём `plugin.json` (и `"allowCrossMarketplaceDependenciesOn": ["claude-webhub"]` в своём `marketplace.json`) и получает `$.webhub`: `page` (зарегистрировать страницу), `push` (отправить ей состояние), `read` (прочитать его обратно), `pull` (забрать нажатия со страницы).
- Страница — целиком свой HTML мода. Она подключает `/hub.js` ради `window.hub` (`onState`, `send`, `onDelivered`, `onSessions`, `lang`, `theme`) и по желанию `/hub.css` с цветами хаба для обеих тем.
- С `scope: 'project'` страница общая для сессий проекта; без него она принадлежит сессии.

Полный контракт — в `types/index.d.ts`, `server/static/hub.js` и [`skills/webhub-mod/SKILL.md`](skills/webhub-mod/SKILL.md).

## Где хранятся данные

Страницы и их состояние лежат в `~/.claude/mods-data/webhub/pages` (внутри `$CLAUDE_CONFIG_DIR`, если он задан), по файлу на страницу. Страница завершённой сессии остаётся в списке, пока ты её не уберёшь (✕); страницы, которые не менялись 30 дней, удаляются при перезапуске сервера.

Сервер отвечает только на `127.0.0.1`. Входа по паролю нет: любой, кто может достучаться до этого порта на машине, видит страницы и может нажимать их кнопки.

## Остановить или удалить

```
/plugin uninstall webhub
```

Контейнер после этого продолжает работать; останови и удали его так:

```bash
docker rm -f claude-webhub
```
